# ربات الینالیزه 🤖💗

ربات دستیار مدیریت گروه‌های تلگرامی، سرگرمی و ثبت داده - نوشته‌شده با Node.js + Telegraf + MySQL.

## نصب و راه‌اندازی

### ۱. پیش‌نیازها
- Node.js نسخه ۱۸ به بالا
- دسترسی به همان دیتابیس MySQL که ربات دیگرتان استفاده می‌کند (یا هر دیتابیس MySQL دیگری)
- یک توکن ربات از [@BotFather](https://t.me/BotFather)

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. تنظیم فایل env.
فایل `.env.example` را کپی کرده و به `.env.` تغییر نام دهید، سپس مقادیر را پر کنید:
```bash
cp .env.example .env
```
- `BOT_TOKEN`: توکن ربات از BotFather
- `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME`: اطلاعات همان دیتابیس مشترک شما
- `MOTHER_ADMIN_IDS`: آیدی عددی تلگرام ادمین‌های مادر، با کاما جدا شده (مثال: `111,222`)

> **نکته مهم:** جداول این ربات همگی با پیشوند `elinalize_` ساخته می‌شوند تا با جداول ربات دیگرتان که روی همین دیتابیس است تداخلی نداشته باشد. در اولین اجرا، اگر جداول وجود نداشته باشند، خودکار ساخته می‌شوند.

### ۴. اجرا
```bash
npm start
```
یا برای توسعه با ری‌استارت خودکار:
```bash
npm run dev
```

### ۵. اضافه کردن به گروه
ربات را به گروه اضافه کرده و **ادمین کامل** کنید (حداقل دسترسی‌های: حذف پیام، اخراج کاربر، بن کردن، محدود کردن کاربر).

## ساختار پروژه
```
src/
  index.js                 # نقطه ورود اصلی و دیسپچر
  config.js                 # تنظیمات مرکزی (از .env خوانده می‌شود)
  database/
    db.js                    # اتصال pool به MySQL
    init.js                  # ساخت خودکار جداول
  services/                 # منطق دسترسی به داده (مقام‌ها، اخطار، بن، علاقه/عصبانیت، ...)
  handlers/                 # پردازش دستورات و دکمه‌های شیشه‌ای
  middlewares/              # میان‌افزارهای Telegraf (اجرای بن، ثبت گروه)
  data/
    messages.json            # تمام متن‌ها و دیالوگ‌های فارسی ربات - آزادانه قابل ویرایش
  utils/                     # ابزارهای کمکی
```

## ویرایش پیام‌های ربات
تمام جمله‌هایی که ربات می‌گوید (پیام صبح‌بخیر، پاسخ ابراز علاقه، پیام‌های خطا و ...) داخل
`src/data/messages.json` هستند. کافیست این فایل را ویرایش کنید و ربات را ری‌استارت کنید؛
نیازی به تغییر کد نیست. برای فیلدهایی مثل `{name}` یا `{target}` در پیام‌ها، مقدار به‌صورت خودکار
جایگزین می‌شود.

## کلمات صدا زدن
پیش‌فرض: `الینالیزه` و `لیزه` (در `src/config.js` → `defaultWakeWords`).
هر ادمین مادر می‌تواند مستقیماً از داخل گروه کلمه جدید اضافه/حذف کند:
```
لیزه افزودن صدا زدن نازی
لیزه حذف صدا زدن نازی
```

## دستورات مقام‌دارها (نیاز به ریپلای روی پیام کاربر هدف)
| دستور | کار |
|---|---|
| `لیزه اخراج` | اخراج + مسدود کردن دائم (در صورت بازگشت، پیام‌هایش حذف می‌شود) |
| `لیزه حذف اخراج` | خارج کردن از لیست مسدودی‌ها |
| `الینالیزه قوانین` | ارسال قوانین گروه |
| `لیزه اسپویلر` | اسپویلر کردن پیام/رسانه ریپلای‌شده |
| `لیزه اخطار` | افزودن اخطار (با رسیدن به سقف، اخراج خودکار) |
| `الینالیزه حذف اخطار` | حذف یک اخطار |
| `لیزه حذف پیام` | حذف پیام ریپلای‌شده |
| `لیزه گزارش فعالیت` | فعالیت اخیر کاربر هدف |
| `لیزه نمایش مقام` | نمایش مقام کاربر هدف |
| `لیزه سکوت <عدد>` | سکوت به مدت N دقیقه، مثال: `لیزه سکوت 10` |
| `الینالیزه لیست زندانی` | لیست اخراج‌شده‌ها (صفحه‌بندی‌شده) |
| `لیزه لیست مجرمین` | لیست گزارش‌شده‌های تاییدشده (صفحه‌بندی‌شده) |
| `لیزه چه خبر` | گزارش فعالیت مقام‌ها در ۲۴ ساعت اخیر |

## دستورات کاربران عادی
| دستور | کار |
|---|---|
| `لیزه اخطار` (ریپلای) | ارسال درخواست گزارش برای تایید مقام‌دارها |
| `لیزه نمایش مقام` (ریپلای) | نمایش مقام شخص هدف |
| `لیزه صبح بخیر` / `لیزه شب بخیر` | پیام تصادفی صبح/شب بخیر |
| `لیزه دوست دارم` / `لیزه عاشقتم` | افزایش ۵٪ علاقه‌مندی الینالیزه (هر ۱ ساعت یک‌بار) |
| `لیزه پروفایل` | نمایش درصد علاقه/عصبانیت و تعداد اخطار |
| `لیزه خسته‌ام` | سکوت تصادفی بین ۲۰ دقیقه تا ۵ ساعت برای خودش |

## دستورات ادمین مادر
| دستور | کار |
|---|---|
| `لیزه ساخت مقام <نام> <سطح>` | ساخت مقام جدید، مثال: `لیزه ساخت مقام پلیس شب 5` |
| `لیزه تنظیم مقام <نام مقام>` (ریپلای) | اختصاص مقام به کاربر هدف |
| `لیزه حذف مقام` (ریپلای) | حذف مقام از کاربر هدف |
| `لیزه تنظیم سقف اخطار <عدد>` | تغییر سقف اخطار قبل از اخراج خودکار |
| `لیزه تنظیم قوانین <متن>` | تنظیم متن قوانین گروه |
| `لیزه پنل` | باز کردن پنل مدیریت مقام‌ها (دکمه‌ای) - هم در گروه هم در پیوی ربات |

در پنل می‌توانید برای هر مقام، تک‌تک دسترسی‌ها (اخراج، اخطار، سکوت، ...) را روشن/خاموش کنید و
سطح (priority) مقام را برای سلسله‌مراتب بالا/پایین ببرید. مقام با سطح بالاتر نمی‌تواند توسط
مقام پایین‌تر اخراج/حذف/تنظیم شود.

## سیستم علاقه‌مندی و عصبانیت
- هر ابراز محبت (`لیزه دوست دارم`) حداکثر هر ۱ ساعت یک‌بار، ۵٪ علاقه اضافه می‌کند.
- عصبانیت فقط با گذشت زمان کم می‌شود (۵٪ در روز، خودکار هر نیمه‌شب).
- تایید گزارش یک کاربر توسط مقام‌دار، ۱۰٪ عصبانیت اضافه می‌کند.
- اخراج کاربر توسط مقام‌ها: ۲۰٪ کاهش علاقه و ۴۰٪ افزایش عصبانیت.
- وقتی علاقه ۱۰۰٪ و عصبانیت ۰٪ شود: مقام موقت ۲۴ ساعته «عزیز الینالیزه» اعطا و در گروه تبریک
  گفته می‌شود، سپس ۵۰٪ از علاقه کم می‌شود.

## نکات فنی
- دیتابیس مشترک: تمام جداول با پیشوند `elinalize_` ساخته می‌شوند و در صورت نبودن، خودکار
  ساخته می‌شوند (`CREATE TABLE IF NOT EXISTS`) — هیچ تداخلی با جداول ربات دیگرتان ندارد.
- ادمین‌های مادر فقط از `.env` خوانده می‌شوند و در دیتابیس ذخیره نمی‌شوند.
- برای mute/سکوت از قابلیت بومی تلگرام (`restrictChatMember` با `until_date`) استفاده شده،
  پس نیازی به کرون‌جاب جداگانه برای پایان سکوت نیست.
- برای اسپویلر کردن رسانه، چون ربات‌ها نمی‌توانند فلگ اسپویلر پیام‌های دیگران را ویرایش کنند،
  پیام اصلی حذف و با `has_spoiler: true` دوباره توسط ربات ارسال می‌شود.

## توسعه بعدی پیشنهادی
- افزودن دستور ویرایش متن قوانین به‌صورت چندخطی از طریق پنل به‌جای دستور تک‌خطی
- افزودن صفحه آمار کلی گروه در پنل (تعداد اخطارها، اخراج‌ها و ...)
- افزودن تست‌های خودکار (unit test) برای سرویس‌ها
